**Running the Sequential and Parallel Prefix Sum Program**

This program implements and compares sequential and parallel versions of the prefix sum (cumulative sum) algorithm in C++. It includes:

* Sequential Prefix Sum
* Blelloch Scan Algorithm
* Chunk Based Parallel Prefix Sum using OpenMP

The program measures the execution time of each implementation, calculates the speedup achieved by the parallel version, and visualizes the results using a Python script.

**Contents**
* prefix_sum.cpp: The main C++ source code file.
* plot_speedup.py: Python script to plot execution times and speedup.
* times.txt: Output file generated by the program containing execution times and speedup.

**Prerequisites**
To run this program, you need:

* A C++ compiler(vsCode) that supports C++11 or later and OpenMP (e.g., g++, clang++).
* Python 3 with matplotlib installed for plotting.

**Setup Instructions**

**1. **Install Dependencies****
* C++ Compiler with OpenMP Support
GNU Compiler Collection (GCC):
* Install GCC if not already installed.
Ensure it's version 4.9 or later to support C++11.

**Python 3 and Matplotlib**
* Install Python 3 if not already installed.

* Install matplotlib for plotting by running this command:
```console
pip install matplotlib
```

**2. Verify OpenMP Support**

Ensure your compiler supports OpenMP:

For GCC:
```console
g++ -fopenmp --version
```

**Compilation Instructions**

**Compile the C++ Program**

Use the following command to compile prefix_sum.cpp with OpenMP support:

```console
g++ -fopenmp prefix_sum.cpp -o prefix_sum
```
**Flags Explanation:**
* -fopenmp: Enables OpenMP support.
* prefix_sum.cpp: Source code file.
* -o prefix_sum: Output executable named prefix_sum

**Running the Program**

**1. Run the Executable**

Execute the compiled program:
```console
./prefix_sum
```
**2. Program Output**

**The program will:**

* Compute the sequential prefix sum.
* Compute the parallel prefix sum using either the chunk based algorithm or blelloch scan depending on which method are you executing.
* Measure and display the execution times for both implementations.
* Calculate and display the speedup.
* Writes the execution times and speedup to times.txt.
* Runs the Python script plot_speedup.py to visualize the results.
